Matrix iteration and uncertainty.ipynb is the code used for trade matrix iteration and uncertainty analysis. The Trade matrix iteration folder contains the input and output data required for the iteration process. In this folder, Trade matrix.xlsx, Consumption.xlsx, and Statistics_production.xlsx are the input datasets. The goal is to cross-validate the production data derived from consumption data and the trade matrix with the production data from statistical sources such as the China Statistical Yearbook. By iterating the trade matrix, the discrepancy between the two sets of data is reduced. Export_after Iteration.xlsx and Trade matrix_after Iteration.xlsx are the trade matrix and export data after iteration.
